통합모바일 앱/ODS 구축
프로젝트 개요

한국투자저축은행 사용자에게 보다 편리한 서비스를 제공하기 위해, 통합 모바일 앱 "key뱅크"와 사내 운영 시스템 ODS를 새롭게 구축했습니다. Websquare5와 Eclipse를 기반으로 각각 모바일 앱과 ODS를 개발하여 기존 서비스 품질을 대폭 개선하였으며 사용자 경험과 운영 효율성 향상이라는 두 가지 목표를 달성했습니다.

앱 설치로 서비스를 이용할 수 있습니다.

keybank keyvisual

1. 메인페이지

대출 만기일을 강조하기 위해 볼드 처리와 하이라이트를 적용하고, 배지(badge)와 진행률(progress bar)로 가독성을 향상시켰습니다.

2. 상품 페이지

상품 정보를 카드 형식으로 구성해 사용자가 쉽게 파악하고, 원하는 페이지로 빠르게 이동할 수 있도록 구축했습니다.

3. 상품 상세페이지

정보를 보다 효율적으로 탐색할 수 있도록 아코디언 형식으로 구성했습니다.

  • 1. 메인 페이지

  • 3. 상품 상세페이지

    정보를 보다 효율적으로 탐색할 수 있도록 아코디언 형식으로 구성했습니다.

  • 오픈뱅킹 등록 페이지

    정보를 한눈에 확인할 수 있도록 체크박스를 카드 형식으로 구성해 구축했습니다.

  • 한도조회 결과 페이지

    조회 결과를 카드 형식으로 구성해 사용자가 정보를 직관적으로 파악할 수 있도록 설계했습니다.

  • 대출 상세페이지

    라디오 버튼과 함께 간단한 정보를 제공하여 사용자가 편리하게 선택할 수 있도록 구성했습니다.
