프로젝트 개요

기존에 딱딱했던 회사 홈페이지를 리뉴얼하는 프로젝트에 참여하여, 기획부터 디자인, 개발까지 전 과정을 수행했습니다. 밝고 친화적인 기업 이미지를 반영하기 위해 회사 캐릭터를 제작해 활용하고, 메인 페이지에는 Instagram을 연동하여 회사 분위기를 효과적으로 보여주도록 구성했습니다.

visit website(↗↗)

*현재는 다시 리뉴얼되서 재구성 했습니다*

왼쪽 - before, 오른쪽 - after

1. splash 화면

페이지 로딩 중에 회사 캐릭터를 활용한 스플래시 화면을 구현해 사용자에게 친근한 인상을 전달했습니다.

2. 메인 페이지

금융권 IT기업의 디지털 전문성을 표현하기 위해 메인 페이지에 네트워크 콘셉트의 동영상을 삽입하고 구성했습니다.

3. 메인 페이지 - floating 버튼

플로팅 버튼에 자주 묻는 질문을 포함하여, 사용자가 언제든지 필요한 정보에 쉽고 빠르게 접근할 수 있도록 구성했습니다.

  • 메인 페이지 - project

    작업물을 직관적으로 탐색할 수 있도록 Swiper를 활용해 슬라이드 구성을 적용했습니다.

  • navigation

    모바일 환경에 최적화된 네비게이션을 구축하기 위해 햄버거 버튼과 트랜지션 효과를 적용했습니다.

  • Piino News Page

    다양한 기기 환경에 대응하기 위해 Flex를 활용하여 반응형 레이아웃을 구현하고, 최적의 화면을 제공했습니다.

반응형으로 구현

사용자들이 편리하게 사이트를 이용할 수 있도록 반응형 디자인을 적용하여, 모바일 환경에서도 쉽게 접근할 수 있도록 구축했습니다. 데스크탑과 모바일 모두에서 최적화된 사용자 경험을 제공합니다.
